2. Memory Management
a. Method Area:
Stores: static variables, Class metadata, methods.
b. Heap Area:
Stores: Instance variables, Objects (references), SCP → String Constant Pool.
c. Stack Area → (Like temporary memory):
Stores: Local variables, Threads, Method execution.
d. Program Counters (PC):
Holds the current and next instructions.
e. Native Method Area:
Used when we connect/communicate with different programming languages (e.g., JAVA → Python, C).
→ These instructions will be stored in the Native Method Area.
3. Execution Engine
a. Interpreter:
.class → Machine → Run (Line by line / instruction by instruction).
b. JIT Compiler → Just In Time Compiler:
↳ When we have repeated instructions / loops,
↳ JIT Compiler picks such code & executes them in a single shot,
↳ Which reduces time (as Interpreter alone takes more time executing line by line).
JIT Compiler + Interpreter → Hybrid (picks what should run how & performs).
c. Garbage Collector:
Trashes / removes the unused references and variables.
