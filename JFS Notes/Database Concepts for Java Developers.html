→ Inner Join
↪ gives common data between tables
select e.emp_id, e.name, d.dept_name from employees e inner join departments d on e.dept_id = d.dept_id ;
→ * won't give any data which doesn't match
→ * won't give values where dept_id is null
→ Left Join
↪ gives entire data on left table
select e.emp_id, e.name, d.dept_name from employees e left join departments d on e.dept_id = d.dept_id ;
→ (inner join + left table data)
* when departments → dept_id is not have any employees
   → it puts null for table entries / it ignores those
* when employee dept_id is null
   → it gives those values with dept_name as null
→ Right Join
↪ gives entire data on right table
select e.emp_id, e.name, d.dept_name from employees e Right join departments d on e.dept_id = d.dept_id ;
→ (inner join + Right table data)
* when dept_id is null in emp table
   → it ignores those values
* when department dept_id is not there in emp table
   → it put null values for that entries & dept_name will be given.
